# 분류 규칙 (웹 등록 모달 vos-analyze 프롬프트와 동일)

원본: `vntg-gw-web/pages/api/generate.ts` `buildVosAnalyzePrompt`, `constants/admin/taxonomy/gws.ts` `GWS_VOS_CLASSIFY_RULES`. 손으로 고치지 말고 원본을 고친 뒤 다시 내보낼 것.

## 출력

한 건당 `summary`(30자 이내 한 줄, 인사말·수식어 제거, "무엇이 필요한가"만) + `l1_code`/`l2_code`/`l3_code` 한 계통.

## 일반 규칙

- L1부터 좁혀가며 결정. 상위가 명확하지 않으면 그 레벨부터 null
- 각 항목의 "— 정의" 문구가 판정 기준. 이름이 비슷해도 정의의 포함/제외 조건을 우선
- "(L3 없음 — L2에서 종료)"로 표시된 L2는 l3_code null
- 분류표에 없는 주제는 해당 레벨부터 null. 어설픈 추측 금지
- summary는 항상 채움. 의미 추출이 어려우면 원문 핵심 단어 사용
- code 값은 분류표에 존재하는 코드 문자열 그대로 (가공·해석 금지)
- l1/l2/l3는 반드시 한 계통 (l2는 l1의 하위, l3는 l2의 하위)
- "문의"·"확인 요청"·"대응" 같은 표현은 유형을 정하지 않음. 무엇에 대한 것인지(결재 설정·연동 데이터·계정·기능 사용 등)로 정함. 이름에 '문의'·'기타'가 들어간 잔여 유형은 대상을 전혀 알 수 없을 때만

## 경계 판정 규칙 (위에서부터 순서대로 적용, 일반 규칙보다 우선)

1. 인증 일원화 — 비밀번호·2단계 인증·로그인 불가·계정 잠금은 대상 시스템(GWS·세아웍스·해외법인 메일 등)과 무관하게 02 > 0206 인증 관리. "세아웍스 비밀번호 초기화"도 020601이다 (040201·040203 아님).
2. 결재 경계 — 결재 양식·결재 문서·결재 오류는 "세아웍스" 표현이 있어도 03 전자결재 운영. 세아웍스 포털·모바일·게시·조직도 관련만 04.
3. 조직도·인사정보 — 조직도 반영·수정, 겸직·전보·사번 변경은 표현과 무관하게 020301. 조직도 연계 모듈(인사연동·동기화) 운영·장애는 040205.
4. 보안 사건 — 해킹 의심·스팸 분석·의심 IP 차단·사건 관련 로그 추출/비밀번호 조치 등 보안 사건의 후속 건은 모두 010303 보안 이슈 대응.
5. 연동 문의 — ERP·세일즈포스·SAP 등 연동/인터페이스/API 스펙·데이터·테스트·테스트 계정·연동 데이터 확인 문의는 040205 (결재 연동 오류만 030302).
6. 팀 관할 외 시스템(SHE·SELIS·ITS·법인차량·문서보안 등) 문의의 접수·이관·담당 안내는 040301.
7. 원 요청 없는 팀 발신 공지·자료 전달은 040302. 처리결과 회신·후속 확인은 원 요청과 같은 유형으로.
8. "문의"·"확인 요청"·"문의 대응"·"진행 상황 확인"·"일정 확인"은 유형이 아니다 — 무엇에 대한 것인지로 정한다. 결재 양식 개발·수정 진행 상황은 030101/030102, 연동 테스트·데이터 확인은 040205, 개발·배포 가능 여부는 040101/040102, 계정 생성 진행 여부는 020101.
9. 결재 설정 문의(대외비·공개 여부·참조/회람 범위·결재선/결재자 지정·접수담당자 권한)는 030103. 결재 화면·버튼·양식 표시 오류는 030301. ERP 상태연동·증빙 반영 오류는 030302.
10. 계정 문의("세아웍스 계정 문의"·테스트 계정·추가 생성·ID 중복 가능 여부)는 020101. 세아웍스 기능 사용 가능 여부·방법(회의실 예약·게시글 수정·앱 설치·활용 현황 조회)은 040202.
11. L3가 있는 L2는 반드시 L3까지 채운다. 결재 양식 관련이면 030101/030102/030103 중 하나를 고른다 (0301에서 멈추지 않는다).
12. 040203 문의 대응은 최후 수단 — 위 규칙과 다른 모든 유형 정의를 검토한 뒤에도 원문에서 대상을 전혀 알 수 없을 때만 사용 (예: 원문이 "세아웍스 문의"뿐). 대상이 하나라도 보이면 그 유형.
13. 판정 불가(사담·원문 불충분)여도 null 대신 04 > 0403 > 040303 기타·판단 불가를 부여한다. null은 분류표에 아예 없는 주제(팀 업무 무관)일 때만.
